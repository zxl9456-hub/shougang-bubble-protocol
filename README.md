# 首钢园 · 霓虹泡泡夜

一个基于 Three.js 的小型像素风泡泡游戏，以首钢三高炉、冷却塔和“雪飞天”大跳台为原型。蓝紫夜景、青色和洋红霓虹、工业钢架、暖色炉光与奶油色复古界面参考用户提供的两张图片；园区为游戏化布局，并非实际地理复刻。

## 玩法与操作

- 单人三关：泡泡在 2.2 秒后十字爆炸，炸完当前关卡全部彩色方块，自动解锁对应的三高炉、冷却塔或大跳台并过关。无需拾取核心或消灭全部机器人。HUD 显示剩余方块和进度，解锁时战场让位给地面像素画：三高炉、双冷却塔和大跳台分别在三关地面上逐行显现。结算面板移到边侧，地面图案持续保留到下一局。角色有三条生命，受击后短暂无敌。
- 一机双人：同一台电脑、同一块键盘，两人各一条生命。最后存活者获胜，同时出局或时间耗尽则平局。当前版本为本机对战，没有远程联网房间。
- P1 / 单人：↑ ↓ ← → 移动，空格放泡泡。
- P2 / 双人：WASD 移动，Enter 放泡泡。Esc 暂停。
- 彩色方块均可炸毁，圆形钢柱和边界保留，爆炸在每个方向的第一个方块处停止，可连锁引爆泡泡。机器人炸毁的方块也计入清理进度；最后一块炸毁即判定完成。
- 手机支持单人触控方向键和泡泡按钮，双人需要实体键盘。
- 地标解锁和可选关卡保存在本机浏览器。点击开始后自动播放 BGM 和音效，右上角可分别开关。暂停与切换到后台时音乐暂停。

## 逐关难度

方块数量由种子随机布局，但每关总量固定递增；同一种子下，后关包含前关的方块布局并增加新的方块。保留四个出生区的转弯逃生路径。双人地图增加到 38 块。

| 关卡          | 方块 | 对手 | 对手移动间隔 | 对手射程 | 放泡泡间隔 | 对手引爆时间 | 时限   |
| ------------- | ---- | ---- | ------------ | -------- | ---------- | ------------ | ------ |
| 三高炉 / 初阶 | 34   | 1    | 0.29 秒      | 2 格     | 3.4 秒     | 2.4 秒       | 260 秒 |
| 冷却塔 / 进阶 | 42   | 2    | 0.23 秒      | 3 格     | 2.6 秒     | 2.1 秒       | 240 秒 |
| 大跳台 / 挑战 | 50   | 3    | 0.18 秒      | 4 格     | 1.9 秒     | 1.85 秒      | 220 秒 |

玩家的移动速度、三条生命和 2.2 秒泡泡引爆时间保持一致。第二、三关对手拥有两条生命，补给概率逐关减少。

## 模型与画面

本次使用已连接的 Blender 制作并导出地标和两名角色的 GLB 素材，所有素材随网站一起托管。Rodin 集成缺少 API Key，未调用 Rodin 或 Mixamo。

- 三高炉：圆形炉体、钢架上部、环形平台与栏杆、大型弧形管道、炉窗、梯架和暖色炉光。
- 冷却塔：双曲线塔身、外部环带与肋条、支撑脚。
- 大跳台：连续坡面、桁架支撑、栏杆与霓虹边灯。
- 角色：薄荷与蜜桃两名可爱机器人，保留圆润大头、笑脸、腮红、短四肢和连指手套，以球形天线及小圆耳区分轮廓，移除复杂机械装甲；Blender 节点动画导出为 Idle、Walk、PlaceBubble、Hit 四个片段，游戏中按事件播放。

静态模型按材质合并，保留轮廓细节并减少绘制次数。Three.js 使用透视大厅、俯视战场、阴影、辉光和更明显的地面反射。新增环绕高炉的霓虹环、探照光束、流动灯带、高架光轨列车、漂浮光点和爆炸扩散冲击波。三关分别采用暖橙、冰青和粉紫主题色，减少动态偏好会暂停环境运动。天空插画由内置图像生成工具制作，只有远景与天空，不含界面。

## 本地运行

使用 Node.js 22.13+ 和 pnpm。

```sh
pnpm install
pnpm dev
pnpm test
pnpm typecheck
pnpm build
```

静态成品位于 `dist/client`。构建使用 Vinext / Vite、React 19、Three.js；界面复用 Shadcn / Base UI。

## GitHub Pages

GitHub Pages 使用 `github-pages/main.tsx` 直接加载同一个 `Game` 组件，无需服务器。模型、像素图、音乐、CSS 和脚本随静态站点一起发布。

```sh
NEXT_PUBLIC_BASE_PATH=/shougang-bubble-protocol pnpm build:pages
```

GitHub 静态成品位于 `dist/github-pages`。仓库网站使用 `/仓库名` 作为路径前缀；自定义域名或 `用户名.github.io` 仓库可省略 `NEXT_PUBLIC_BASE_PATH`。

`.github/workflows/pages.yml` 会在推送到 `main` 后运行测试、类型检查、构建及 Pages 发布。在仓库 Settings → Pages 中选择 GitHub Actions 作为发布来源。原有 `pnpm build` 和 Sites 配置继续用于原网址。

## 结构

- `components/game/engine.js`：关卡、碰撞、爆炸、补给、AI 与结算。
- `components/game/input.js`：键位及单人/双人控制分配。
- `components/game/assets.js`：GLB 加载、材质合并、角色动画混合。
- `components/game/environment.js`：园区、管廊、铁路、霓虹、天空与地面反射。
- `components/game/atmosphere.js`：主题灯光、霓虹环、流动灯带、列车、光束与冲击波。
- `components/game/mosaic.js`：地面像素地标、逐行显现和清空后的奖励展示。
- `components/game/models.js`：辅助几何、场地道具与材质。
- `components/game/scene.js`：相机、照明、粒子与游戏实体动画。
- `components/game/Game.tsx`：循环、键盘、进度、暂停与 WebMCP 功能检测。
- `components/game/Interface.tsx`：大厅、规则、HUD、结果和移动端控件。
- `components/game/audio.js`：BGM 播放管理与分层 Web Audio 音效，支持独立开关与暂停。
- `public/models/`：Blender 地标模型、两套新角色和旧版本素材。
- `public/art/pixel-skyline.png`：生成的像素天空插画。
- `public/mosaics/`：三个像素地标的地面网格数据。
- `scripts/render-ground-mosaics.mjs`：从 Blender 地标 GLB 离线投影、光照取色和栅格化，生成 96 × 72 的地面像素数据。网页将像素绘制为单个实例化方块网格。
- `docs/skyline-prompt.txt`：该插画的完整生成提示词。
- `tests/`：规则、键位和模型/动画集成检查。

## 音乐与音效

`public/audio/neon-factory-loop.mp3` 为本次原创编写并渲染的 116 BPM、16 小节、约 33 秒无歌词电子配乐，含鼓组、贝斯、和弦铺底、旋律和琶音。ChatCut 音乐生成工具未连接，因此没有调用 Mureka；使用 `scripts/compose-bgm.mjs` 制作 PCM，再由 FFmpeg 编码为 MP3。完整编曲源码随项目保留，无第三方音乐采样。放泡泡、爆炸、方块破碎、拾取、受击、地标解锁和对局结算使用独立合成音效，爆炸带噪声冲击与低频层，解锁有和弦提示并暂时降低 BGM 音量。

## 验证范围

34 项自动检查覆盖游戏规则、300 个随机地图、机器人模拟、真实倒计时后的方块破坏、最后方块解锁、方向键与双人控制、两套模型的合并边界及动画、场景几何构建、固定递增方块布局、对手能力递增、地面图案逐行显现、环境特效与 BGM 启动/暂停/独立静音和各类音效事件。另检查 TypeScript 与静态构建，并在 Blender 中检查两名可爱角色及三个地面图案的实际渲染。未执行浏览器视觉或交互测试；构建与自动检查不能替代实际浏览器游玩验证。WebMCP 有功能检测，当前环境没有可调用的 WebMCP 验证上下文。
